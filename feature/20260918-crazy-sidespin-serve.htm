「CRAZY SIDESPIN SERVE」で学ぶ横回転サーブ

最終更新日 2026.09.18 出典：MLFM Table Tennis

言葉はいらない。「見せる」だけで魅了する。「説明がないからこそ、自分で考えて見る」。

「言葉による解説が一切ないのに、世界中の卓球ファンから支持されている解説動画」

今回ご紹介するのは、YouTubeチャンネル『MLFM Table Tennis』の「Learning CRAZY Sidespin Serve | MLFM Table Tennis Tutorial」です。

サーブを出した瞬間、ボールが横へグッと逃げていく。

タイトル通り、テーマは強烈なサイドスピン（横回転）サーブ。

横回転系のサーブは、単純に回転量が多いだけでなく、バウンド後の軌道やレシーブ時の飛び方をずらしやすいのが面白いところです。

この記事では、動画を見ながら特にチェックしたいポイントを、アマチュア目線で整理してみます。

横回転は、「ボールを横へ飛ばす回転」ではない

横回転サーブというと、最初は「ボールを横方向へ振ればいい」と考えがちです。

ただ、実際に重要なのはラケットを大きく横へ動かすことよりも、ボールの側面をどれだけ薄く、速くこすれるか。

厚く当てればスピードは出ても、回転は弱くなりやすい。逆に、インパクトを薄くできると、同じフォームでもボールの曲がり方が一気に変わってきます。

薄くこする

ボールを前へ押すより、表面を一瞬だけこするイメージ。回転量を出す土台になります。

手首を最後まで固めない

腕全体を振り回すのではなく、インパクト付近で手首と前腕をコンパクトに使うと、鋭い回転を作りやすくなります。

ラケット角度を変える

同じ横方向のスイングでも、ラケット角度や触る位置を少し変えることで、横下・横上・ナックル寄りの変化につなげられます。

見るべきは、インパクトだけではなく「1バウンド目」

回転サーブを練習するとき、どうしてもラケットとボールが当たる瞬間ばかり見てしまいます。

でも、試合で効くサーブにするには、自分のコートのどこに1バウンド目を落としているかもかなり重要です。

短く止めたいのか、相手コートで横に逃がしたいのか、深く突き刺したいのか。狙いによって1バウンド目の位置も変わります。

動画を見るときのコツ：インパクトだけを追わず、「トス → 当てる位置 → 1バウンド目 → 相手コートでの変化」までひと続きで見ると、サーブ全体のイメージを作りやすくなります。

大きなフォームより、「同じ構えから変える」

強烈なサーブを見ると、つい大きなスイングを真似したくなります。

ただ、実戦で厄介なのは、派手なフォームそのものよりも、似た構えから違う回転が出てくること。

横回転だけでなく、横下回転、横上回転、さらに回転量を落としたサーブを同じ準備動作から出せるようになると、レシーバーは一気に判断しづらくなります。

「強い1本を作る」だけではなく、同じフォームで何種類か作るところまで考えると、サーブがそのまま得点パターンになります。

MLFM Table Tennisによる「Learning CRAZY Sidespin Serve」。強烈な横回転サーブをテーマにしたチュートリアル動画です。

サーブだけで終わらせず、3球目までセットで考える

横回転が強いほど、相手のレシーブも横へ流れたり、少し浮いたり、コースが限定されたりしやすくなります。

そこで大切なのが、サーブを出した直後に「効いた、効かなかった」で止まらないこと。

このサーブを出したら、どこへ返ってきやすいのか。そこまで想定して3球目を待てるようになると、サーブが単発の技術ではなく、攻撃の入口になります。

特にペン表や前陣タイプなら、横へ流れたレシーブを待って早い打点で狙う、少し浮いたボールをミートで叩く、といった形にもつなげやすそうです。

まとめ

「CRAZY SIDESPIN SERVE」という名前はかなり派手ですが、練習するときに見るべきポイントは意外とシンプルです。

薄くこする。1バウンド目を見る。同じフォームから変化を作る。そして3球目まで考える。

横回転サーブは、ただ回転量を増やすだけではなく、相手のレシーブ位置や打球感覚をずらすための技術です。

サーブ練習のときは、動画を何度か止めながら、ラケットの動きだけでなくボールが台の上をどう動いているかまで見てみると、新しい発見があるかもしれません。
