KILLER YG SERVE

言葉はいらない。「見せる」だけで魅了する
究極のキラーYGサーブ講座

最終更新日 2026.08.31 出典：MLFM Table Tennis

「説明がないからこそ、自分で考えて見る」

「言葉による解説が一切ないのに、世界中の卓球ファンから支持されている解説動画」をご存じでしょうか。

今回ご紹介するのは、YouTubeチャンネル『MLFM Table Tennis』が投稿した、「Learning KILLER Reverse Pendulum Serve」です。

MLFMは、馬龍（Ma Long）や樊振東（Fan Zhendong）から影響を受けた、ベトナムを拠点とするクリエイターチーム。

タイトルにある「Reverse Pendulum Serve」とは、いわゆる「YGサーブ」のことです。

手首を内側から外側へと押し出すような独特のスイングから繰り出されるこのサーブは、強力な回転と読みづらさを持つ反面、習得の難易度が高いことでも知られています。

日本ではandroの濱川さんによる「モンスターYG」のレクチャー動画などをご存じの方も多いのではないでしょうか。

習得できたらカッコいい。
一度は覚えてみたい、憧れのサーブだと思います。

言葉ではなく、「見せる」YGサーブ講座

この動画の面白いところは、YGサーブ単体だけで終わらないこと。

YGサーブからの3球目、5球目、さらにその先のラリーまで、実戦を想定した連携がかなり多く紹介されています。

しかも、細かな言葉による説明はほとんどありません。

説明がないからこそ、「今のインパクトはどうなっていた？」「サーブのあと、どこで3球目を待っている？」と、自分でしっかり見て分析することができます。

これだけ多くのパターンを見せてもらえると、「自分もYGサーブを覚えてみたい」と練習の励みにもなりそうです。

スローモーションだから見える、インパクトの違い

動画では、多角的なアングルから撮影されたスローモーション映像もふんだんに使われています。

特に注目したいのが、横下回転と横上回転の違い。

横下回転

ラケットヘッドを落とし、ボールの側面から下側を素早く捉える。

横上回転

よく似たフォームを保ちながら、ボールの側面から上方向へとラケットを動かしていく。

インパクト付近の細かなラケット角度や軌道の違いが見やすく、何度か繰り返して見るだけでもフォームのイメージを作りやすい動画になっています。

レッスンから「実戦」へ

そして動画の後半では、YGサーブを実際のゲームの中でどう使うのか、ラリーシーンへと移っていきます。

MLFM Table Tennisによる「Learning KILLER Reverse Pendulum Serve」。YGサーブのフォームから実戦での連携まで、映像を中心に見せてくれます。

CHAPTER｜見るポイント

YGサーブ → 3球目 → 5球目 → ラリーまでを見ることができるので、単に「サーブの打ち方を覚える動画」というより、そのサーブを試合でどう使うのかまでイメージできるところがおすすめです。

まとめ

YGサーブというと、「超上級者が使う難しいサーブ」というイメージを持っている方も多いと思います。

ところが、この動画を見ていると不思議と親しみやすく、「これならちょっと練習してみようかな」と思わせてくれます。

技術を細かく説明するのではなく、良いフォーム、インパクト、3球目、5球目、そして実戦まで、とにかく見せる。

たまには説明を聞くのではなく、じっくり「見る」ことから新しいサーブを覚えてみるのも面白いかもしれません。
